# Source Sans 3 font origins

These unmodified static WOFF2 font files are self-hosted by Dun for consistent offline rendering.

- Family: Source Sans 3
- Styles: normal 400 (Regular), 600 (Semibold), 700 (Bold)
- Designer: Paul D. Hunt, Adobe
- Copyright: Copyright 2010-2022 Adobe, with Reserved Font Name 'Source'.
- License: SIL Open Font License 1.1; the complete copyright notice and license are in SourceSans3-OFL.md.
- Official source: https://github.com/adobe-fonts/source-sans/tree/ed1808970eb3c7301c9a523bee26473ba0bb62fa/WOFF2/TTF
- Release: 3.052R
- Source commit: ed1808970eb3c7301c9a523bee26473ba0bb62fa
- Retrieved: 2026-10-01
- No font modification, subsetting, or format conversion was performed.
- Verified WOFF2 signature: `wOF2` for all three files; static weights 400, 600, and 700; no variable axes.
- Default lining figures are tabular: all ten digits have equal advance widths at each weight (497, 513, and 528 units respectively, on a 1000-unit em). The countdown retains CSS `font-variant-numeric: lining-nums tabular-nums` for semantic intent and fallback fonts.
